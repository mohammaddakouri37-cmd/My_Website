## 🌐 صفحات الموقع

1. **الرئيسية (`index.html`)**:
   - شريط تنقل متجاوب يدعم الأجهزة الذكية.
   - معرض صور متحرك (Hero Carousel) لأبرز الفعاليات.
   - تصفح الفعاليات حسب التصنيفات الرئيسية.
   - قسم فعاليات بارزة هذا الشهر وأحدث الفعاليات.
   - قسم بطاقات فريق العمل بالمشروع.
   - زر التمرير السلس للأعلى (Scroll to Top).

2. **دليل الفعاليات (`events.html`)**:
   - محرك بحث نصي مباشر لتصفية الفعاليات.
   - فلترة ديناميكية حسب التصنيف (مسابقات، علمي، ثقافي، رياضي).
   - فلترة حسب الشهر والتواريخ (ديسمبر 2026، يناير 2027).
   - عداد مباشر لعدد النتائج المطابقة مع إشعار عند عدم وجود نتائج.

3. **تفاصيل الفعالية (`event.html`)**:
   - عرض ديناميكي لبيانات الفعالية وفق المعرّف (`id`).
   - عرض معلومات التاريخ والموعد، الموقع الجغرافي، والتصنيف.
   - نافذة تفاعلية (Bootstrap Modal) لحجز مقعد وتسجيل الحضور مع التحقق من صحة المدخلات.
   - بطاقة موقع الفعالية وخريطة جغرافية توضيحية.
   - ميزة مشاركة رابط الفعالية (Web Share API مع النسخ التلقائي للحافظة كبديل).
   - عرض فعاليات أخرى ذات صلة تلقائياً.

4. **عن الدليل (`about.html`)**:
   - رؤية ورسالة المنصة وأهدافها لخدمة طلبة الجامعة.
   - بطاقات تعريفية مفصلة بأعضاء فريق التطوير وأرقامهم الجامعية.
   - خطوات تقديم فعالية ومراجعتها واعتمادها.
   - معايير وضوابط نشر الأنشطة في البيئة الأكاديمية.

5. **اتصل بنا (`contact.html`)**:
   - نموذج تفاعلي للتواصل واقتراح فعاليات جديدة.
   - التحقق من صحة المدخلات (Form Validation) للبريد الإلكتروني والحقول الإلزامية وعرض تنبيهات Bootstrap.
   - بطاقة معلومات التواصل الرسمية للجامعة ومقرها وساعات الدوام.
   - روابط منصات التواصل الاجتماعي.

## 🎨 التقنيات المستخدمة

- **HTML5**: هيكلية دلالية حديثة تدعم التوافقية وسهولة الوصول (Accessibility & Semantics).
- **CSS3**: نظام ألوان أكاديمي عصري، تدرجات احترافية، متغيرات CSS (:root)، وخط Cairo من Google Fonts.
- **Bootstrap 5.3 RTL**: تصميم شبكي متجاوب تماماً مع الشاشات المختلفة ودعم كامل للاتجاه من اليمين لليسار.
- **JavaScript (ES6)**: معالجة الأحداث، الفلترة اللحظية، التحقق من النماذج، ودعم التمرير والمودال التفاعلي.
